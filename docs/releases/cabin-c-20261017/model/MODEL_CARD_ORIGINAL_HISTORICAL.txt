Modification notice: The base model was locally modified on 2026-10-16/17 through response-only QLoRA fine-tuning
on synthetic, limited cockpit intent/repair data; the adapter was merged into BF16 weights and converted to
Q8 LiteRT-LM with a 2048 cache profile. These are modified weights, not an official Qwen release.
No pruning or parameter deletion was performed. No teacher-logit distillation is claimed.

Scope: produce proposed JSON patches for rearFan, mediaVolume and navVolume. The host application supplies
pending/context state, validates output, preserves state, handles driver authorization and performs mock actuation.
This is not a general vehicle controller and is not a validated in-vehicle deployment.
